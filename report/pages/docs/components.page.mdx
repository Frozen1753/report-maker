# Components

Each component has its own page, with a live example first. Look inside its "En savoir plus" for the full prop list and more variants.

- [Link](/docs/components/link): internal references and external URLs.
- [Callout](/docs/components/callout): admonition-style boxes, in six variants.
- [Collapsible](/docs/components/collapsible): optional detail, out of the main reading flow.
- [Separator](/docs/components/separator): a plain rule or a labeled break between sections.
- [Tabs](/docs/components/tabs): mutually-exclusive content.
- [Comparison](/docs/components/comparison): a toggle between two states, such as before and after.
- [Figure](/docs/components/figure): an image, gif or video with a numbered caption and a lightbox.
- [Code](/docs/components/code): inline code and highlighted blocks.
- [Term](/docs/components/term): an inline word with a tooltip.
- [Mermaid](/docs/mermaid): diagrams, pre-rendered as SVG.
- [Glossary](/docs/glossary): terms defined once, usable anywhere.
